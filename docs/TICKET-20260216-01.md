# Ticket: TICKET-20260216-01
## Problem: Null Check Operator Used on a Null Value
**File**: `lib/core/services/auth_service.dart`

### Description
The application crashed with a `Null check operator used on a null value` error.

**Root Cause**:
In the `_isExpired()` method, the `expiry` variable (which is nullable `DateTime?`) was being accessed with the force-unwrap operator `!` without verifying it was not null. Even though `expiry == null` was checked in the first part of the OR condition, the second part `DateTime.now().isAfter(expiry!)` could still be evaluated if the first part was false, or under certain race conditions / logic flows where the compiler couldn't guarantee non-nullability.

Additionally, the `init()` method was void and lacked error handling, meaning initialization errors would be silent or crash the app without useful logs.

### Original Code (Buggy)
```dart
  Future<void> init() async {
    // ... code ...
    expiry = _decodeExpiry(token);
    // ... code ...
    if (_isExpired()) { // Could crash here
       // ...
    }
  }

  // FORCE UNWRAP `expiry!` causes crash if expiry is null
  bool _isExpired() => expiry == null || DateTime.now().isAfter(expiry!);
```

## Solution
1.  **Safety**: Refactored `_isExpired` to use the null-aware operator `?.`.
    *   `expiry?.isBefore(DateTime.now())`: If `expiry` is null, this returns `null`.
    *   `?? true`: If the left side is null (meaning no expiry), we default to `true` (expired), ensuring we force a token refresh or logout.
2.  **Robustness**: Updated `init()` to return `Future<AuthService>` and wrapped the logic in a `try-catch` block.
    *   This ensures `Get.putAsync` works correctly.
    *   It catches JSON decoding errors or other exceptions during init, logging them instead of crashing silently.

### Fixed Code
```dart
  Future<AuthService> init() async {
    try {
      // ... code ...
      // TICKET-20260216-01: Added error handling
      if (_isExpired()) {
        final success = await refreshToken();
        if (!success) logout();
      }
    } catch (e, stack) {
      logError('AuthService init error: $e\n$stack');
    }
    return this;
  }

  // TICKET-20260216-01: Safe null handling
  bool _isExpired() => expiry?.isBefore(DateTime.now()) ?? true;
```
